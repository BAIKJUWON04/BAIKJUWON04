## 3. 수상 및 주요 성과

### 🏆 2023 안동대학교 해커톤 우수상

### [ESP32 Smart Home](https://github.com/BAIKJUWON04/2023-ESP32-Smart-Home)

ESP32를 활용하여 웹에서 조명과 출입 장치를 제어할 수 있는 스마트홈 시스템을 개발했습니다.

`ESP32` `C++` `Wi-Fi` `Web Server` `Servo Motor` `NeoPixel`

---

### 🏆 2024 안동대학교 · 동아대학교 연합 해커톤 인기상

### [AI Code Security Analyzer](https://github.com/BAIKJUWON04/2024-AI-Code-Security-Analyzer)

C 소스코드를 분석하고 보안상 문제가 될 수 있는 부분을 확인할 수 있는 웹 기반 코드 분석 서비스를 개발했습니다.

`C` `Python` `Flask` `HTML` `AI` `Code Analysis`

---

### 🚀 2019 한국코드페어 2차 본선 진출

### [IoT Smart Doorlock](https://github.com/BAIKJUWON04/2019-IoT-Smart-Doorlock)

ESP8266과 카메라 및 센서를 활용하여 출입 상태를 감지하고 데이터를 원격으로 확인할 수 있는 사물인터넷 기반 출입 관리 시스템을 개발했습니다.

`ESP8266` `C++` `Firebase` `ArduCAM` `Sensor` `IoT`
